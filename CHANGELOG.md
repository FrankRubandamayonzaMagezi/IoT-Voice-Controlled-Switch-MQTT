## [1.0.0] - 2026-07-10

### Added

- Initial release of the IoT Voice Controlled Switch (MQTT).
- ESP32 firmware for MQTT communication.
- Local Mosquitto MQTT broker support.
- Python voice assistant using SpeechRecognition.
- Text-to-Speech (TTS) feedback using pyttsx3.
- MQTT topic publishing for ON/OFF commands.
- ESP32 web dashboard for monitoring and manual control.
- Real-time LED status updates.
- Project documentation and installation guide.
- MIT License.
- Python virtual environment support.
- Requirements file for dependency installation.
